First release: monthly cost estimates for Lambda, API Gateway, DynamoDB on-demand, SQS, SNS, Step Functions Standard, and CloudWatch Logs from stated inputs and a dated snapshot of the public AWS list prices (us-east-1), with assumptions, exclusions, and a sensitivity table, and comparisons of Lambda memory sizes (from measured durations), x86 against Graviton, and HTTP against REST APIs. Every figure is labeled estimated. It makes no AWS calls.
